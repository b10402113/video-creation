## 02｜視覺基調與層級

先確立一個短結論和一個支持圖形，再補充數據或一句說明（R1、R2 規範）。圖形紋理比文字弱；全場最多一個主視覺焦點。以內容決定橘色的位置。網站的目錄、編號和 CTA 屬於網站功能；簡報整張畫面預設無角落標籤或頁碼（R1）。

## 03｜色彩設計

| 角色 | Token（預設） | 值 | 使用 |
|---|---|---|---|
| 紙白 | `--color-bg` | `#f2efe8` | 一般簡報和網站底。 |
| 卡面 | `--color-surface` | `#faf8f2` | 紙白上的簡報卡；網站淺卡改用 `#f4f2f1`。 |
| 黑底 | `--palette-black` | `#131311` | 簡報深底、半黑分割。 |
| 墨色／奶油 | `--color-text` | `#1c1a16`／`#e8e2d2` | 淺底／深底的標題、正文和主要圖形。 |
| 次要文字 | `--color-muted` | `#6f6a5c`／`#8d8775` | 淺底／深底的附註。 |
| 橘色 | `--color-accent` | `#ff6b1a` | 選中卡、圖表重點、點陣或大字；淺底橘不承擔小字。 |
| 例外黃 | `--palette-yellow` | `#f5a623` | R1 明文指定才用，限 1–2 個小部位；預設不顯示。 |

簡報值由 R1 規範與 CSS 確認。網頁深色有獨立卡面 `#242422`、卡文字 `#e8e2d2`、卡線 `#2f2d28`；頁面底為 `#131311`、本文 `#e8e2d2`（暗色過場結束值）（R2 實測）。影片底 `#1d1b17`、資訊面 `#29261f` 是依畫面近似的實作建議，原色值未知；R3f 的綠色勾只服務於狀態。本例只保留一個橘色焦點，不把綠、藍等功能色帶回簡報色票。

## 04｜字體與文字

| 角色 | 設定 | 來源 |
|---|---|---|
| 展示標題 | Outfit 500；參考封面 `clamp(48px, 6.5vw, 100px)`、行高 1.02、字距 −2px | R1 實測 |
| 段標 | Outfit 500；`clamp(30px, 3.6vw, 52px)`、行高 1.05、字距 −1px | R1 實測 |
| 正文 | Outfit 400；`clamp(13.5px, 1.3vw, 16px)`、行高 1.65 | R1 實測 |
| 像素重點 | Doto 900；英文標題只強調 1–2 個詞，與前文相接時加 0.15em；允許大數字，禁止正文 | R1 規範 |
| 段前短標 | Outfit 400／大寫／字距 6px；只在需要分類的網頁或文件展板用 | R1 規範、R2 觀察 |
| 真人段落 | 主標多為厚襯線感；展示用 Georgia 700 代替，R3f 有無襯線對照；輔文字維持無襯線 | R3 觀察／建議 |

簡報標題以六個英文詞內和一行輔助文字為方向（R1）；中文以看一眼讀完為準。中文正文 fallback 用系統黑體，中文重點用色彩或字重，不強制使用 Doto。簡報標題留短，仍要說完觀點（R2）；塞不下就拆成下一幕。

## 05｜圖片、插畫與圖示

- **點陣當主要圖形。** 在固定網格上按亮度調整每顆點半徑；點距 8–11px，半徑上限約點距的 0.4 倍，兩層內。淺底用墨點 `rgba(28,26,22,.88)`，深底用奶油點 `rgba(232,226,210,.85)`；橘色第二層只在需要時用。字區底下的點降到約 20% 不透明度，或挖空（R1 規範）。
- **圖示。** 簡報卡用 10×10 或 12×12 單色像素格、預設空心；重點卡才用橘色實心。影片中的功能圖示另有細線版本，與像素主圖分工（R1 規範／R3 觀察）。
- **人物影片。** 平視的頭肩或半身、暖中性室內光、大圓角，底部低對比點陣；輪廓與圖解不得重疊（R3 觀察）。建議鏡頭框長寬比接近 1:1，圓角 22%，先保住眼睛與頭頂，再調 `object-position`。人像在右為常見手法，也可左置或退到右下。

## 06｜版面與構圖

| 版型 | 可重用做法 |
|---|---|
| 簡報／中心聚焦 | 標題與一張圖同軸置中；一般內容邊距取畫布寬度 7–8%（R1 brand book 實測）；16:9 為這次實作建議。 |
| 簡報／圖文並排 | 兩欄以圖或比較為右欄，欄距約畫布寬度 4%（R1 實測）；直接標註，不把圖例擺很遠。 |
| 網頁／案例集合 | 紙白首屏讓標題居中、下方用弱點陣，案例按題組收納，細節放在展開層（R2 觀察）；窄版讓卡片降成單欄（本展板建議）。 |
| 影片／人物＋圖解 | 原截圖皆為 1920×1080（16:9），圖解與人框並排；展板建議約 1:1 欄寬、6% 左右邊距及 5% 欄距。字幕、臉部、連接線分區；可切換左右，複雜圖解時縮小人物（R3 觀察／建議）。 |

固定比例成品應按實際交付尺寸重排和驗收；狹窄的規格展示頁可讓影片示意圖改為上下排列，僅用來閱讀規格。

## 07｜元件、資訊圖與圖表

- **簡報卡：** 0 圓角、2px 墨邊、6px × 6px 無模糊硬影；18px × 20px 內距、52px 圖示欄、欄距 16px。重點卡換橘邊與橘影；深版改奶油邊與淡奶油影（R1 規範）。
- **網站卡：** 5px 圓角、細邊、預設無硬影；淺版線 `#dcd7cb`，深版線 `#2f2d28`（R2 實測）。
- **資訊圖：** 線和端點用同一個畫布座標系，或讓連接線獨立佔欄；標籤貼近節點。圖表預設用中性色，留一處橘色給結論（R1、R2）。比較用條圖，趨勢用折線。示範數值不代表原內容。

## 08｜變體與動態

| 範圍 | 覆蓋 |
|---|---|
| 預設簡報 | 紙白／Outfit／Doto／方角卡；深色段交換前景背景。預設靜態，小量點陣變化可作例外（R1）。 |
| `data-variant="web"` | 換網站的卡面、細邊和小圓角；可搭 `data-theme="dark"`。原網頁有明暗切換與全螢幕案例，展板並排呈現兩種樣式（R2）。 |
| `data-variant="video"` | 近黑、襯線感替代字型、大圓角人像。截圖不能確認動畫曲線與時長；此例只展示靜態畫面（R3）。 |

## 09｜驗收清單

- [ ] 三秒內能指出唯一重點；移除多餘強調、重複口白和裝飾。
- [ ] 一幕一結論，圖形能說明結論，標籤就近；左右或上下版順序不改變。
- [ ] 簡報卡為硬角；網站卡與人像圓角各限自己的範圍。
- [ ] 字不蓋在濃點陣上；小文字用前景色，必要時有文字／位置輔助，不只靠色彩辨識。
- [ ] 圖示、字體、色票與 `token.css` 一致；桌面和窄螢幕可閱讀、無橫向裁切。
