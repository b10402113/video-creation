# Gary Chen｜教學畫面方向

以三支教學影片的 16 張截圖為基礎。視覺像一個安靜的深色工作台：炭灰底承接文件、工具和流程圖，白字讓結論先被讀到，橘色指出這一刻要看的步驟、節點或變化。畫面用來解釋操作和觀念，適合工具教學、功能拆解和工作流示範。

1. **讓章節資訊固定在邊緣。** 頂端用細分段進度線，左上用小章節標；旁白字幕固定靠下置中。觀眾可以隨時知道講到哪裡，中間留給此刻的內容。
2. **先排閱讀順序，再安排卡片。** 背景與卡面只差一階。用白字、間距和對齊來分層；一個步驟用細橘線或橘邊指出，其他物件維持灰階。紅綠只在有狀態含義時出現。
3. **讓視覺物件像真的能用。** 以檔名、訊息、分支、清單或局部介面承接抽象概念。這些物件提供證據，字幕補一句解釋。檔名、編號、時間等需要對齊的資訊用等寬字。
4. **依講解任務換構圖。** 宣布觀點用「橘色大編號＋白色短結論」；拆解關係用文件卡與連接線；比較或決策用並欄和分流；操作證據用單一介面裁切。開場需要比喻時，可短暫使用暖橘與冷藍發光插畫。
5. **該停就拆一幕。** 若兩條路徑同時搶焦點、介面文字縮到看不清，或內容碰到字幕區，就換下一個講解畫面。通常不需要額外背景紋理或整頁發光。

[畫面要求](畫面要求.md)包含取樣、數值和 16 張圖的來源索引；[設計系統展示](design-system.html)有六種自製畫面示意。這是根據截圖整理的可製作規格，原字型和動態未獲確認。
