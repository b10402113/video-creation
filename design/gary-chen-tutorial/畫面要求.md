## 02｜視覺基調與層級

- **底層**：平坦炭灰，跨三支影片一致。僅在需要立體感、介面遮罩或故事意象時加暗影／光暈（M01、M02、G02）；不要全幕加紋理。
- **資訊層**：卡片稍亮，次要線條與文字降成灰色。用細邊和內距把內容組在一起，不必每一塊都上色。
- **主焦點**：只圈出這一刻正在講的物件，可用橘色外框、節點、數字或走線。相同資訊可以用同色呼應；章節切換層與字幕不爭奪主視線（M02、M05、G01、G03、O01）。
- **閱讀順序**：先看主結論或圖解，再讀小標籤；字幕一般置於正下方，獨立於圖表內容。沒有對應字幕時可空著（G06、O03）。

## 03｜色彩設計

下表為 JPEG 平坦區／實色字取樣近似及可製作值。壓縮、反鋸齒、發光會影響局部像素；不是品牌原始色碼。

| 語意 token | 值 | 場景與證據 |
|---|---|---|
| `--color-bg` | `#262626` | 三部影片的平坦邊緣主色；16 張皆在平坦區取到（實測）。 |
| `--color-surface` | `#323232` | 文件、階段卡；M02、G03 平坦區實測。 |
| `--color-text` | `#ffffff` | 主標與字幕字心；O01 實測。 |
| `--color-subtitle-bg` | `#090909` | 黑色字幕底；O01 多數平坦像素實測。 |
| `--color-accent` | `#fe8d00` | 大編號／有效路徑／活動項；O01 字心實測。橘邊、光暈的實際像素可不同。 |
| `--color-muted`、`--color-line` | `#b4b4b4`、`#484848` | 次字與一般細邊；依觀察採用的建議值。弱線只分層，不承擔重要資訊。 |
| `--color-warning`、`--color-success` | `#ed6146`、`#0fb086` | M03 警告柱與 M04 綠勾近似取樣。只用於有意義的狀態，同時加圖形或文字。 |

選中卡可加橘色低不透明度底，橘描邊與一般文字仍分清楚。進度線的已過段落用暗橘，當前段用亮橘，未到段用中灰（觀察／建議；`--color-progress-past` 約 `#8e5a20`）。

## 04｜字體與文字

截圖觀察：大標、卡名、字幕以粗黑體為主；檔名、數字、章節計數器常用等寬或近似等寬字形。O01 的橘色主編號比灰色總數大很多，中文字與英數要在同一行可辨。無字型檔，以下都是實作建議。

| 用途 | 1920×1080 建議尺寸與行高 | 規則 |
|---|---|---|
| 大編號／短結論 | 176 / 1；白標 90px / 1.16 | 主編號等寬粗字；總數縮成約一半，置中一行；結論一至兩行。 |
| 卡標／卡內文字 | 46px / 1.16、32px / 1.38 | 標題 700，明細 500；短檔名可用等寬，長資料必要時分行。 |
| 章節標 | 21px / 1.38 | 前綴橘色等寬數字，文字灰白；固定在左上。 |
| 字幕 | 42px / 1.28 | 700、白字，常態一行。句子太長先按語意分段，避免縮小文字。 |

中文示範以 PingFang TC、Microsoft JhengHei／系統黑體 fallback；檔名和編號用系統等寬字，中文回退黑體。字距預設正常。英數斜線前後留小間距。

## 05｜圖片、插畫與圖示

- **介面和文件優先**（M02–M07、G02–G04、G06）：重畫能解釋流程的文件／指標，讓端點名能直接讀到。若用真實產品介面，裁切到操作區、保留辨識介面的邊框或視窗頭；環境降亮，僅圈要看的欄位。以自有或獲准素材替代範例截圖。
- **圖示**：細線或單色輪廓配短標；功能角色可用簡單表情圖形。原產品圖示只在說明特定工具時保留。用低對比灰表示不活躍、愈靠近講解愈清楚（G01、G04、G05）。
- **意象插畫**：M01 為觀察到的開場例外：單一橘色角色、冷藍承接物、少量符號像泡泡向上排，外緣有柔光。置中，光暈局部衰減；不把發光與冷藍帶到每個資訊卡。示範藍 `--color-illustration` 是新增近似值。
- 16 張內未見真人或全畫面背景照，不從這批圖推定人像構圖。

## 06｜版面與構圖

實測畫布 1920 × 1080。以下是調自相對位置的製作建議，可縮放到等比例畫布；窄版是規格展板本身的閱讀方式。

| 版型／區域 | 可重用規格 |
|---|---|
| 共同畫框 | 頂線高約 3px，分段中留 4px 左右。章節標距左約 2.3%、距頂約 2.6%（G03、O01 觀察）。內容從左右各 5% 開始；規格建議把關鍵圖文放在距頂 13% 至底部 79% 這區。 |
| 字幕 | 靠下水平置中，底部約留 5%，黑底隨文字寬延伸；建議最大 82% 寬。留 2 行高度相容性，字幕與內容分層，不要蓋住節點名。 |
| 大編號／短結論 | 步驟號和總數共一行，白色結論獨立一行，上下整組置中（O01）。 |
| 文件路徑／分流 | 兩欄或三欄：入口、處理、結果。邊線／箭頭走欄間；多路比較用同一基準線。使用 SVG 時讓路線與端點共座標，窄版可改直排（M02–M04、G01、G04）。 |
| 工具／步驟對照 | 三等寬卡；例如 5% 外邊、2.7% 欄隙近似 G03。未揭曉的第三張可以只留數字和虛線，不要填無關文字。 |
| 局部介面／時間線 | 介面示意主佔約三分之二，附註短放另一欄（G02）；單一水平時間軸用等距點和就近標籤（O02、O03）。窄版保留順序與文字，不直接把字一同縮到不可讀。 |

## 07｜元件、資訊圖與圖表

- **工作卡**：預設中灰填充、灰色細邊、0 或柔陰影；可做小卡上疊一層文件。建議圓角 18px、邊 2px、內距 24px（1920px 座標）；G03 的大卡橘邊選中、虛線只表示空位。小膠囊圓到底，保持短字。
- **流程**：中性路徑灰線、當前路徑橘線、有實際風險的節點用珊瑚紅；線端帶箭頭或端點圓點。節點貼標，狀態以「！」、「✓」或描述輔助色彩（M03、M04、O03）。
- **文件／介面視窗**：標題列比內文略深或略亮，左邊放檔名或視窗點，右邊只留相關計數。高亮行用暖色底或橘描邊；避免文件裡每一行都搶過圖表。
- **量化圖**：M03 出現垂直用量槽與門檻，O03 可見時間節點；未見完整座標圖。重做時保留單位和門檻標，避免用顏色代替數字。展示頁的內容與數值皆為示意，不代表原影片資料。

## 08｜變體與動態

| 任務 | 覆蓋方式 |
|---|---|
| 章節／短結論 | 保留共同背景與章節線。內容去掉容器，改大橘號加白標（O01）。 |
| 文件／流程 | 用薄邊卡和明確連線，明暗對照，按需要加入有語意的紅綠狀態（M02–M07、G01、G04）。 |
| 對照／介面證據 | 等寬卡、虛線待揭曉，或實際介面加單一標記；藍只屬遠端節點，品牌圖示原色局部保留（G02、G03、G06）。 |
| 意象開場 | 橘與藍小面積發光、中央群組（M01）。 |
| 動態 | 僅有靜態截圖，不能確認動畫方向、時長與曲線。若製作版需要動態，可依講解節點切換選中狀態；本展板無自動動畫。 |

## 09｜驗收清單

- [ ] 在輸出尺寸看得出章節、主內容和字幕三層；字幕與圖表、節點標籤留有間隔。
- [ ] 單一主焦點，選中、未揭曉和警告可透過形狀或文字分辨；外部工具原色不主導整幕。
- [ ] 卡內和窄畫面文字可讀；長檔名正常換行，連線與端點不脫落。
- [ ] 960×540 等比例預覽仍看得出流程和字幕重點；手機窄版展板可直排，沒有橫向溢出。
- [ ] 色票與 CSS 角色一致；保留來源索引、近似取樣、替代字型和未確認的動態說明。
