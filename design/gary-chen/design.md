# Gary Chen｜炭灰 × 橘色焦點

來源：[AI 開始會做夢了？Claude 記憶拆解！](https://www.youtube.com/watch?v=ZJkfmrbmuFg&t=1s)。取樣依原影片播放時間：[30 格總覽](reference/sheet-001.jpg)、[逐格索引](reference/manifest.json)。以下是參考畫面的重建規則；樣片的切點由新配音時間決定。

## G0 風格檔

| 項目 | 製作規則 |
|---|---|
| 領域、受眾、口吻 | 科技解說；給想理解 AI 工具運作方式的一般使用者。先以生活比喻建立畫面，再用真實文件、操作或數據解釋機制。 |
| 底色策略 | 16:9、1920×1080@30。各章共用實色炭灰幕底；以章節條、構圖和證據紙面區分段落。選深底是為了貼合指定參考片的深色示範介面與弱光插畫。 |
| 色彩 | [theme.json](theme.json) 是影片 token 來源。橘色只標當下講解焦點；藍色只用在插畫或對照側；綠色只表示完成。畫布、卡面和來源字各自固定，不按鏡頭另選色。 |
| 字階 | 繁中介面採 PingFang TC、檔名和代碼採等寬。章標約 22 px，來源約 24 px，字幕 42 px；標題與字幕用較粗字重，來源及內文用常規字重。並列或滾動數字用等寬數字，數值附單位。 |
| 材質與卡 | 解說面板為深灰薄線、低圓角；原文證據保留白紙面，只有來源素材容器用投影。若使用獨立實錄，整片用同款雙細線 `ThemeFrame kind="hairline"`；靜圖與產品自帶介面不再套假播放器框。 |
| 資料圖與標注 | 網格用低對比線；圖形依資料提供單位、軸與刻度；橘色只指當前讀點。流程用同款線稿、線寬與箭頭；框選依畫面實測的目標座標，隨素材移動。 |
| 素材與底床 | 比喻用 GPT 藍橘插畫；證據用來源截圖，操作用去識別的實錄或明標「示意」的介面。一般情況保持實色底床。 |
| 能量 | 低至中。以字級錨點交接主體，最多一個閱讀焦點；動作落定後由慢推維持畫面，不加掃光或持續彈跳。 |

對應 Talkcraft：選用 `gary-chen` 後，`select-design.mjs` 將 token 存為影片工程的 `remotion/src/design.json`，由 `theme.ts` 讀取。這份文件也用於填寫 SHOTBOOK 的 G0 風格檔。每鏡另在蒙皮行記錄如何把原動效卡套入這些規則，保留卡的核心緩動、層級與音效，並以本片字級錨點安排觸發。

以前由三支影片整理的版本保存在 [Gary Chen 教學通用版](../gary-chen-tutorial/design.md)。

## 參考畫面與重建規則

| 參考時間 | 觀察 | 製作規則 |
|---|---|---|
| 0:01 | 單一藍橘意象置中，周圍保留大量炭灰 | 主體約佔寬度 28–34%，不要再加大標；用 GPT 生圖產出可去邊的插畫，與畫布漸融 |
| 0:03–0:07 | 同一插畫退到左側，右側加入 X 貼文；兩個數據逐次取得焦點 | 沿用同一張圖做位置與尺度接力；真實截圖留右欄，依口白先看觀看量，再看收藏量 |
| 0:09–0:15 | 左欄白底封面、右欄白底短摘錄，橘底標記重點 | 來源在左卡下緣；同一時間只有一處亮，低對比休眠元素留在原槽 |
| 0:18–0:34 | 藍色睡眠側臉 → 灰色事件條、橘月牙和長期記憶框 → 亂線變燈泡 | 比喻用插畫；步驟用 SVG 與文字分層。資訊一律從左往右流，動作落在旁白對應的動詞上 |
| 0:37–0:58 | 灰色 session 條入記憶槽，修正時才出現綠勾；三張卡輪流亮起 | 橘色指當前焦點；綠色只表示完成。卡片數、亮度與順序要能跟旁白對上 |
| 1:07–1:34 | 單一終端窗 → 兩窗對照 → 資料夾樹 | 窗殼、訊息列、寫入列、線條與文件卡分層；重建示範介面要清楚標成示意 |
| 1:50–3:30 | 真實 Finder、模型圈、左右文件、架構堆疊 | 實際操作用乾淨的示範專案取證，路徑不含私人值。兩欄共用基線；只在比較組允許次要藍色 |

- 1920×1080，30 fps。背景約 `#252525`，字幕底 `#0b0b0c`、暖橘 `#ed9640`、閱讀白 `#f5f4f1`。色碼是重建用值，見 [theme.json](theme.json)。
- 頂端約 3 px 分章線；左上約 x40 / y26 放「01 / 03 · AI 也會做夢」（原片是 06 章，樣片依新稿三章）。字幕 42 px 半粗，距底 60 px，單句硬換、素排。
- 內容垂直集中在 y140–830；檔名用等寬字。證據可用白紙面，其餘面板沿用深灰。沒有主持人素材就不留主持人框。
- 轉場以同物件縮移、橘線承接或短疊化。相機每鏡只做 1.00→1.04 左右慢推；讓口白焦點在縮圖、數字和框線之間交接。
- 參考截圖只用來辨識風格與摘錄有來源的證據。插畫、文字、流程元件各自重建，使構圖可以換稿和調色。
